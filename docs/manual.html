VoxPad manual

VoxPad 1.0 · Windows 10/11 · x64 and ARM64

VoxPad is a soundboard that plays sounds into your microphone, so everybody in your voice chat or game hears them, while you hear your own copy on your speakers. It is modelled on Soundpad: one sound at a time, global hotkeys, categories, a hotbar, a recorder, an editor, text-to-speech, automatic push-to-talk ("Auto Keys") and a remote-control API for Stream Deck-style tools.

1. Overview and audio routing (read this first)

Honest note on how the microphone part works. Soundpad ships a kernel audio driver extension that injects sound into your real microphone device, so every app hears it without any device switching. VoxPad does not ship a kernel driver. Instead it renders your voice + the sound into the playback side of a virtual audio cable, and your voice apps record from the cable's recording side. In practice this means one extra step: in Discord, Teams, OBS or the game you must select the cable's recording endpoint (for VB-CABLE that is "CABLE Output") as the microphone.

Signal path

Physical microphone(s)  ──► voice gate ──┐
                                         ├──► mixer ──► virtual cable playback endpoint ("CABLE Input")
Sound file ──► normalisation ──► slot ────┘                        │
                                                                   └──► apps recording from "CABLE Output"
Sound file ──► slot ──► your speakers (own copy, through the Windows volume mixer)
  • Mix (default): others hear your voice and the sound together.
  • Block voice (Preferences > Audio): while a sound plays, your voice is muted with a 5 ms ramp, so the sound replaces your voice entirely.
  • One sound at a time. Starting a new sound stops the current one on every output. There is no overlapping playback, queue or fade.
  • The speaker copy is a separate output on the playback device you choose. Its volume slider is bound to the Windows volume mixer (VoxPad's session on that device).

Status and Refresh

Preferences > Devices shows a Status line: green Good with the name apps must select, amber for warnings (no microphone ticked, Stereo Mix caveat), or red with the reason (no cable installed, endpoint disabled, Windows microphone privacy blocks desktop apps, cannot open the cable). Refresh re-enumerates devices and restarts the routing. The same state is shown as a green/red dot in the main window's status bar; hover it for the message. Hot-plugging devices triggers an automatic refresh.

2. First-time setup

  1. Install a virtual cable. Download VB-CABLE from https://vb-audio.com/Cable, run the installer as administrator and reboot once (the driver needs it the first time). Voicemeeter works as well.
  2. Start VoxPad and open File > Preferences > Devices. Leave Setup mode on Auto-select. Status should read Good. Apps must select 'CABLE Output' as their microphone. If it is red, press Refresh and read the message.
  3. Tick "Use" next to your real microphone in the Microphones list so your voice is mixed into the cable. Nothing ticked = the default communications microphone is used. Do not tick the cable itself.
  4. Pick your speakers (the device for your own copy). Default = the Windows default playback device.
  5. Discord: User Settings > Voice & Video > Input device = CABLE Output. Turn off Noise Suppression (Krisp), Echo Cancellation, Automatic Gain Control and Advanced Voice Activity; set Input Sensitivity manually. Discord's filters treat soundboard audio as noise and remove it.
  6. Teams / Zoom / games: select CABLE Output as the microphone and disable noise suppression where offered.
  7. Measure your voice once (click the microphone icon in the toolbar, or Preferences > Audio > Measure voice…). The result becomes the normalisation target so sounds come out at your speaking level.
  8. Drag a folder of sounds into the window and press a key. Done.
If Windows' microphone privacy is set to deny desktop apps, VoxPad shows an Access denied dialog at start. See Troubleshooting.

Playback toolbar

Left to right (each item can be hidden in Preferences > Interface > Toolbar items):

  • ▶ Play – plays the selected sound according to the current play mode. ▶🔊 Play on speakers and ▶🎤 Play on microphone force one output.
  • ⏸ Pause/resume, ⏹ Stop, ⏮ Previous, ⏭ Next (previous/next relative to the playing row in the current, sorted and filtered, view).
  • Track timer "elapsed / total". Double-click it to select and scroll to the playing sound.
  • Seek slider. Click or drag to seek. The fill is red while others can hear the sound (it is on the microphone path) and blue when it only plays on your speakers (speakers-only mode, or the virtual cable is not available).
  • Speaker volume icon (click = mute/unmute) and slider. Speakers only; it is the same slider Windows shows for VoxPad in the volume mixer, so changes made there are mirrored.
  • Microphone level meter. Shows your microphone peak. Click the 🎤 icon to open the voice measurement.

Categories panel (left)

  • All sounds is always the first entry. It cannot be renamed, removed or hidden. Its order defines each sound's index (the number used by index hotkeys and the remote API).
  • Right-click an empty area or a category for: Add category…, Add subcategory…, Rename…, Remove category, Play random, Set 'play random' hotkey…, Colour…, Hide category.
  • Drag a category onto another to nest it (drop on the lower half) or before it (drop on the upper half). Drag sounds from the list onto a category to add them; hold Shift while dropping to move instead of copy. Drop files or folders from Explorer onto a category to import straight into it.
  • A sound can be in several categories. Removing it from a category (right-click > Remove from this category) keeps it in All sounds; Remove (Del) deletes it from the list everywhere.
  • The info panel below the tree shows the selected category's name, count and total duration, and has a Hide category checkbox. Hidden categories disappear from the tree unless Window > Show hidden categories is on; their hotkeys keep working.
  • Four icon sizes: Window > Category icon size. The icon takes the category's colour.

Sound list

  • Columns: # (position in the current category), Tag (Artist – Title from the file's metadata, otherwise the file name without extension), Duration, Hotkey, Play count, Last played on. Columns can be resized and reordered by dragging the headers; right-click a header (or use Window > Columns) to hide/show columns.
  • Click a header to sort (natural order: sound2 before sound10); click again for descending, a third time to return to manual order. Manual reordering by drag-and-drop or Alt+↑/↓ only works while no sort is active. Preferences > Interface > Disable sorting turns header sorting off completely.
  • Multi-select with Ctrl/Shift+click. Right-click for the context menu (Play, Play on speakers, Play on microphone, Edit file…, Set hotkey…, Remove hotkey, Colour…, Move to category ▸, Remove from this category, Copy/Cut/Paste, Remove, Reset play count, Select in Explorer).
  • Double-click a row to play it; double-click the Hotkey cell to set the hotkey. F2 also opens the hotkey dialog.
  • Drop files or folders from Explorer anywhere on the window; folders are scanned recursively for AAC, FLAC, M4A, MP3, MP4 audio, OGG, Opus, WAV and WMA. Dropping onto a row inserts at that position. Files already in the list are not duplicated.
  • Each sound can have a colour (swatch before the tag; also used by hotbar tiles). Missing files are shown grey and struck through; the status bar reports how many are missing when a list loads.
  • Instant search: just start typing while the list has focus; the text goes to the search box above the list and filters by tag. Enter cycles through matches, Ctrl+Enter plays the selected match, Esc clears the filter.

Hotbar (bottom)

  • A paged grid of colour-coded tiles (default 8 columns × 2 rows × 4 pages; change under Window > Hotbar size…). Pages are switched with the ▲/▼ buttons or Ctrl+PgUp/PgDn.
  • Drag one or more sounds from the list onto a tile; several sounds fill consecutive tiles. Left-click a tile plays it. Right-click: Set hotkey…, Remove hotkey, Colour…, Remove from hotbar.
  • Drag a tile to another tile (same or other page) to move it. Hold Ctrl while dragging to keep the tile's own colour; without Ctrl the tile falls back to the sound's colour. Hotkeys live on the sound, so they always follow the tile and are the same on every page.
  • Hotbar layout and tile colours are stored in the sound list file.

Status bar

  • Left: the result of the last operation; warnings are shown in red.
  • Trial text (when not registered) and the routing dot (green = Good, red otherwise; hover for the reason).
  • Play mode indicator – click to cycle Speakers + Microphone → Microphone only → Speakers only.
  • Hotkeys – double-click to enable/disable (struck through when off). Right-click: Pass hotkeys to the active application, Hotkey overview….
  • Auto Keys – double-click to toggle. Right-click: Troubleshooting….
  • Repeat and Continue – click to toggle (bold when on).

Themes, languages, tray

Preferences > Interface: Light, Dark or Native style (Native is forced automatically when Windows high contrast or a screen reader is active); 21 UI languages (applied after a restart); Start minimized; Minimize to the system tray; Closing the window minimizes to the tray. The tray icon's menu offers Show VoxPad, Stop and Exit; double-click restores the window. Launching VoxPad a second time just shows the running instance.

4. Hotkeys

Hotkeys are global: they work when VoxPad is not focused, including in fullscreen games (see Troubleshooting for elevated games). Anything goes: a single key, any combination with Ctrl/Alt/Shift/Win, a bare modifier key, and mouse buttons Middle, 4 and 5 (left and right only together with a modifier).

Setting and clearing

Right-click a sound > Set hotkey…, double-click its Hotkey cell, or press F2. In the dialog press the combination; Enter saves, Del or Backspace clears, Esc cancels. Assigning a hotkey that is already used by another sound or category moves it (the old binding is removed). Special hotkeys are reserved and cannot be given to a sound.

Advanced options

  • Pass hotkeys (default off): when off, a matched key is swallowed before the foreground app sees it (key-down and key-up). Turn on if the game must also receive the key.
  • Auto stop (default on): sounds started by a hotkey ignore Repeat and Continue and simply stop at the end. Sounds started from the UI or the remote API follow Repeat/Continue.
  • Allow left/right modifiers: LCtrl+A and RCtrl+A become different hotkeys.
  • Same hotkeys in all categories (row-based): the hotkey assigned to row N plays row N of whichever category is selected.

Hotkey overview (Window menu or the Hotkeys indicator) lists every binding: sounds, category random hotkeys, special hotkeys and the numpad/index gestures.

5. Auto Keys (automatic push-to-talk)

When a sound starts on the microphone, VoxPad can press your game's or Discord's push-to-talk key for you. Configure entries under Preferences > Hotkeys > Auto Keys.

Press modePress and hold for the sound's duration: key goes down when the sound starts and up when it stops, finishes, is paused or replaced. Press before and after: a short tap at start and another tap at the end.
Only if played by hotkey (default on)Fires only for sounds started by a hotkey, not by clicking in the UI or via the remote API.
ConditionAlways · Foreground app is fullscreen (window covers its whole monitor; borderless windows count, the desktop/taskbar do not) · A listed app is running · A listed app is in the foreground. The app list is process names, one per line (e.g. discord.exe).

Auto Keys fire only in microphone play modes (Speakers + Microphone or Microphone only) and only when the microphone path is actually running. VoxPad ignores its own injected key events, so an Auto Key can never trigger a VoxPad hotkey.

Troubleshooting dialog (Help menu, or right-click the Auto Keys indicator): shows the global state, the play mode, the routing status, the foreground app and whether it is fullscreen, and for the last played sound the result for every entry with the exact reason it did or did not fire ("Entry is disabled", "Sound was not started by a hotkey…", "Foreground window is not fullscreen: 'Notepad' 1200x800 on monitor 1920x1080", …).

6. Sound lists, backups, import/export, storage

Sound list files

  • VoxPad lists are .vpl (JSON). They store references to the audio files, categories, order, hotkeys, colours, hotbar tiles and play statistics — never the audio itself. Soundpad .spl lists can be opened (File > Load); they are imported best-effort and must be saved as .vpl.
  • VoxPad edits a working copy (working.vpl in the data folder) that is autosaved every 5 minutes when something changed, and on exit. The title bar shows the list path and an asterisk while there are unsaved changes; File > Save writes your file.
  • At every start a dated backup of the list is written to backups\<name>-YYYY-MM-DD.vpl (one per day, kept 30 days). File > Restore sound list… lists them and replaces the current list with the chosen backup.
  • Recent lists are kept in File > Recent sound lists (10 entries).

Import

  • Add sound files…, Add folder… (recursive) or drag-and-drop. Formats: AAC, FLAC, M4A, MP3, MP4 (audio), OGG, Opus, WAV, WMA. Title/artist/duration are read from the file's tags on a background thread.
  • Import from web…: paste a direct URL to an audio file and optionally a file name; the file is downloaded to your Music\VoxPad folder and added to the list.

Export

  • Export > Sound files… copies every audio file of the list into a folder you choose and writes a new .vpl there that points at the copies with relative paths, so the whole folder can be moved to another PC and loaded there.
  • Export > Preferences… writes a .vpprefs file (device ids and window placement are stripped). Import preferences… loads one; restart VoxPad afterwards.

Statistics

Per-sound play count and last-played date count microphone plays only (speakers-only plays are not counted). File > Statistics… shows the all-time total (kept across lists), the list total, launches and the most played sounds; both per-sound and global counters can be reset there or from the Edit menu.

Command-line flags and portable mode

  • VoxPad.exe --clean resets the preferences to defaults but keeps the sound list.
  • VoxPad.exe <file.vpl> – installed VoxPad registers .vpl, so double-clicking a list opens it.
  • Portable mode: place an empty file named portable.txt next to VoxPad.exe. Everything is then stored in a Data folder beside the executable.

7. Recorder (Ctrl+R)

  • Source: Speakers (what you hear — a loopback of the playback device chosen in Preferences > Devices) or Microphone (the device under "Microphone for the recorder").
  • Format: M4A (AAC, default), WAV (16-bit) or MP3. Everything is captured and saved as stereo 48 kHz.
  • Insert: the new file is added at the end of the list or at the beginning (into the selected category, or All sounds).
  • Auto-normalize to a target (default 89 dB ≈ −23 LUFS; you are warned above 99 dB because that clips) and Trim silence (below −50 dBFS at start and end, 50 ms padding) are applied on stop.
  • Max recording time (default 300 s, 0 = unlimited). While recording, audio is buffered uncompressed in %TEMP%\VoxPad, so RAM stays flat for long takes; the file is deleted after encoding.
  • The peak meter and the timer show the live level and length. Play last take previews the processed take on the speakers.
  • Special hotkeys Start recording / Stop recording work with the window open or closed (the window opens on start). A short notification beep plays on the speakers before capture starts so it never ends up in a microphone recording (disable in Preferences > Recorder).

9. Text to speech (Ctrl+T)

  • Uses the Windows SAPI voices installed on the PC; pick one in the Voice box and adjust the rate slider.
  • Enter previews the text on the speakers. Ctrl+Enter (or Send to mic) plays it according to the current play mode, i.e. into the microphone.
  • Save to list synthesises the line to a file in the recorder format/directory and adds it to the list (at the end or beginning per the recorder's Insert setting).
  • The special hotkey Play text-to-speech text speaks the current text of the TTS window to the microphone from anywhere.
  • TTS audio goes through the same normalisation as files and counts as a microphone play (trial plays, Auto Keys).

10. Normalisation and voice measurement

VoxPad measures loudness per EBU R128 / ITU-R BS.1770 (K-weighted, gated). Like Soundpad it shows loudness on a positive "dB" scale: dB = LUFS + 112, so 89 dB is −23 LUFS and the voice target of 74 dB is −38 LUFS.

  • Voice measurement (toolbar 🎤 icon or Preferences > Audio > Measure voice…): talk normally for about 8 seconds. The integrated loudness becomes the normalisation target. A good microphone level gives more than 74 dB; if the result is lower, raise the microphone level in Windows and measure again.
  • Dynamic (default): before a sound starts, its first 6 seconds are analysed and a gain is applied; while it plays the measurement continues and the gain is refined once a second (half-way towards the new value, so the level settles without pumping).
  • Full file: the whole file is analysed before playback and the result is cached (by path, size and modification time), so long files start instantly the second time.
  • Gains are computed per channel (left and right separately); a silent channel borrows the other's gain. Boosts and cuts are limited to ±30 dB, and a soft limiter prevents clipping on the cable.
  • Normalisation is applied to the microphone path only. Your speaker copy is unchanged — use the speaker volume slider for yourself.

12. Trial, registration, streamer mode

  • Trial limits: at most 10 sounds in the list (imports beyond that are refused with a status message) and 10 microphone plays per launch; after that microphone plays are refused until VoxPad is restarted. Speakers-only plays are not limited. The status bar shows the remaining plays, and the title bar carries "[Trial]".
  • Register (Help > Register…): enter the licensee name and the serial. The serial is verified offline (an ECDSA signature over the name) and stored in license.dat in the data folder. I/1 and O/0 are interchangeable, dashes and spaces are ignored.
  • Hide my name (streamer mode) – in the Register dialog or Preferences > Interface – masks the licensee name in About and Register, so it is not visible on stream.
  • Remove license in the Register dialog deletes license.dat.

13. Remote Control API

VoxPad listens on the local named pipe \\.\pipe\VoxPadRemote (current user only). A client writes one request per line and reads one JSON response line. Requests can be JSON objects or plain-text shorthand.

ShorthandJSONEffect
version{"cmd":"version"}App version
status{"cmd":"status"}Play mode, playing/paused, index, tag, position, duration, speaker level
list{"cmd":"list"}All sounds in index order: index, id, tag, colour (#RRGGBB), duration, hotkey, play count, missing
categories{"cmd":"categories"}Category tree (id, name, parent, count)
play 3 [mic|speakers|both]
play air horn		{"cmd":"play","index":3,"target":"mic"}
{"cmd":"play","name":"air horn"}
{"cmd":"play","id":"<guid>"}		Play by index (All sounds row), by name (exact, then substring) or by id; target defaults to the current play mode
stop / pause / random{"cmd":"stop"} …Stop; toggle pause; random sound (optional "category":"<guid>")

The reference client voxpad-remote.exe (installed next to VoxPad) accepts the same commands as arguments (voxpad-remote play 3 mic, voxpad-remote raw '{"cmd":"list"}') or runs an interactive shell when started without arguments; its source is a small example for Stream Deck / Touch Portal plugins.

14. Troubleshooting

"Access denied" – Windows microphone privacy

If Windows blocks desktop apps from the microphone, VoxPad cannot read your voice and shows a red status "Access denied". Fix: Settings > Privacy & security > Microphone → turn on Microphone access and Let desktop apps access your microphone, then press Refresh in Preferences > Devices. VoxPad offers to open that settings page for you.

Nobody hears the sound

  1. Preferences > Devices must say Good. If it says no virtual microphone was found, install VB-CABLE and reboot.
  2. The voice app must record from CABLE Output, not from your real microphone.
  3. Disable noise suppression / echo cancellation / AGC in the voice app — they remove soundboard audio.
  4. The seek bar must be red while playing. Blue means the sound only reaches your speakers (speakers-only mode or no cable).
  5. Trial: after 10 microphone plays per launch, plays are refused (status bar message).

Hotkeys do nothing in a game

Windows does not deliver keyboard hooks from a normal process into a window that runs elevated (as administrator). Run VoxPad with the same elevation as the game, or run the game unelevated. Also check that the Hotkeys indicator is not struck through.

Drag-and-drop from Explorer does not work

Windows blocks drops from an unelevated Explorer into an elevated window. VoxPad warns in the status bar when it runs as administrator; start it normally (the installer never needs the app to run elevated) or use File > Add sound files….

Voice sounds delayed or chopped

Raise Microphone latency in Preferences > Devices (30 → 50 ms) on slow machines. The capture and the cable run on different clocks; VoxPad compensates drift automatically (±0.5 % rate trim).

Diagnostic report

Help > Troubleshooting… > Create report writes a zip to %TEMP%\VoxPad with the log, the device list, the routing status, the last Auto Keys evaluation and your preferences (device ids only — no license data). Attach it to bug reports. Crash dumps are in %ProgramData%\VoxPad\crashdumps.
